# USB-to-UART

A compact, custom-designed USB-to-UART converter PCB based on the CH340G USB-to-Serial IC. This project converts USB communication into UART serial signals, making it useful for programming, debugging, and serial communication with microcontrollers and embedded systems.

# Features

1. USB Type-A interface for connecting to a computer.
2. CH340G USB-to-UART bridge IC.
3. UART TX and RX communication interface.
4. 4-pin output header for easy connectivity.
5. External crystal oscillator circuit.
6. Dedicated mounting holes for PCB installation.
7. Custom-designed schematic and PCB layout.
